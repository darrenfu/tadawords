# Tada Words development and delivery pipeline

The pipeline is now maintained as routed modules so agents load only the rules
needed for the current task. Start at the
[Agent Protocol index](AgentProtocol/README.md).

The R0-R4 risk model, `check-changed`/`check-pr`/`check-rc` commands, one-writer
session contract, first context compaction checkpoint, evidence reuse, resource
leases, device policy, and guarded merge rules are normative in those modules.
