# Tada Words v0.7.25 — Family Sync Profile Erasure Retry

- Build: `2026072301`
- Issue: `#111`
- Batch: `family-sync-erasure-retry-v0.7.25`

## User-visible change

When Profile deletion shows **Deletion needs attention**, tapping **Try again**
now immediately retries every affected deletion instead of silently respecting
an earlier background backoff window.

## Safety

The retry targets only durable, nonterminal Profile-deletion tombstones already
in `needs_attention`. It preserves their identities and retry histories, never
recreates deleted Profiles or child data, never retries completed erasures, and
keeps account and route validation fail-closed.

## Validation

- Regression coverage proves ordinary synchronization still respects durable
  backoff.
- Focused coordinator coverage proves Parent retry clears that backoff and
  completes the exact tombstone.
- Guardian presentation coverage proves **Try again** calls the dedicated
  erasure retry route and then rereads lifecycle state.
- Exact-HEAD simulator, signed TestFlight, and physical-device acceptance remain
  separate delivery gates.
