# Tada Words v0.7.43 — Word Pool quest reconciliation

**Version:** `0.7.43`

**Build:** `2026072501`

**Batch:** `import-v0.7.43`

**Issue:** [#127](https://github.com/darrenfu/tadawords/issues/127)

## What changed

- Read and Write reconcile each persisted daily plan against the complete active
  Word Pool before a new run launches.
- Deleted or inactive prompts are removed from Today, replay, and completed-day
  Practice Again runs without requiring the parent refresh control.
- Eligible candidate prompts refill vacated New and Review slots up to the
  configured limits; an exhausted pool produces a shorter or unavailable run.
- The canonical daily-plan ID, completed-Today fact, reward grant, attempts, and
  learning history remain unchanged.
- Prompt hydration reads active entries only, so a Family Sync deletion that
  arrives after planning fails closed instead of briefly presenting the removed
  prompt.
- Existing raised-limit expansion and reward-free Practice Again behavior remain
  intact.

## Exact-HEAD acceptance

Automated source, simulator, signed-artifact, and physical-device evidence must
name the unchanged final PR HEAD. Preserve existing app data: do not uninstall,
reset, or replace learning records.

Verify Read and Write separately on one iPhone and one iPad:

1. Start or complete Today so its plan is persisted.
2. Delete one planned word in Parent → Manage Words without tapping refresh.
3. Re-enter Today or Practice Again and confirm the deleted word is absent.
4. Confirm an eligible replacement appears when available; otherwise confirm the
   run is shorter or unavailable.
5. Confirm completed Today evidence, its reward, and prior attempts remain
   present and Practice Again grants no new reward.
