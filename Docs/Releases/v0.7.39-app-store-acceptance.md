# v0.7.39 App Store acceptance candidate

Version `0.7.39` (build `2026072413`) is the exact candidate for the remaining
App Store 1.0 acceptance work.

## Candidate scope

- Preserve the established product contract: Made for Kids with Apple's `6–8`
  primary age band and a public/in-app Profile range of ages 3–8.
- Retain the v0.7.38 contextual Speech Recognition and Microphone permission
  flow.
- Add `Scripts/install-production-device.sh` so a signed production build can
  be installed in place only after its bundled persistence readers are proven
  compatible with the device's saved production data.
- Keep the production installer fail-closed: it does not uninstall the current
  app, reset permissions, or modify the copied preflight snapshots.

## External acceptance status

This source record does not claim App Store Connect completion, TestFlight
installation, production CloudKit acceptance, privacy-traffic acceptance,
screenshot upload, build upload, or human acceptance. Those gates must be
recorded against the immutable release HEAD.
