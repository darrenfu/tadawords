# v0.7.32 release alignment

Version `0.7.32` (build `2026072406`) aligns three App Store release surfaces
without changing the app identity, CloudKit containers, monetization, or
existing profile storage.

## Product age range

- Tada Words is made for children ages **3–8**.
- First-run creation, child profile creation, and Parent profile editing all
  offer the same ages 3 through 8.
- Historical snapshots can still decode durable legacy ages, but a new
  create/edit write cannot set an age outside 3 through 8.
- Apple App Store Connect does not offer a combined 3–8 Kids Category band.
  The release owner must choose one Apple band (`5 and under` or `6–8`) before
  App Review approval.

## Privacy and reviewer alignment

- Family Sync remains off by default and requires an explicit parent opt-in.
- The synchronized and device-local data boundary is defined by
  `Docs/FAMILY-SYNC-DATA-MANIFEST.md`.
- The 74 Twemoji picture hints remain bundled and available offline; there is
  no runtime picture-hint CDN request.
- Core review does not require a Pawgoo account or credentials.

## Compatibility

Existing profile IDs, learning records, word pools, rewards, CloudKit routing,
Keychain voiceprints, and LocalQA storage remain unchanged. No automatic age
migration is performed.
