# Tada Words v0.7.40 — visible app version diagnostics

**Version:** `0.7.40`

**Build:** `2026072414`

**Batch:** `app-version-diagnostics-v0.7.40`

**Issue:** [#130](https://github.com/darrenfu/tadawords/issues/130)

## What changed

- Parent Home → App & Family → Privacy & Support shows the exact installed
  marketing version and build number in a Dynamic Type footer.
- Family Sync shared diagnostics advance to schema 3 and include separate,
  privacy-safe `App version` and `App build` fields.
- Both surfaces use the same live bundle-metadata presentation instead of
  hard-coded release values.
- Missing or malformed bundle metadata produces a stable `unavailable`
  fallback and cannot inject extra diagnostic lines.
- Shared diagnostics continue to exclude bundle identifiers, signing identity,
  embedded Git commits, Apple Account data, Profile identity, and child data.

unchanged final PR HEAD. Preserve existing app data: do not uninstall, reset
privacy state, switch Apple accounts, or replace learning records.
