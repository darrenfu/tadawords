# v0.7.44 Star Feedback

Version: `0.7.44`  
Build: `2026072502`  
Issue: [#135](https://github.com/darrenfu/tadawords/issues/135)

## Product change

- Read, handwriting Write, and letter-keyboard Write now share one top star-progress surface.
- A correct response sends a complete star from the answer area into the exact next empty slot. The short gold trail fades behind the star, and the slot commits only at arrival.
- An incorrect response releases a transient star from that exact slot, falls to a plane 10% above the bottom, performs one clearly visible short bounce, then fully removes itself.
- Duplicate callbacks cannot commit the same star twice. Incorrect feedback never adds or removes earned progress.
- Every incorrect response creates a fresh feedback event, so repeated misses always replay both the exact-slot fall and its sound.
- Reduce Motion commits success immediately and keeps incorrect progress unchanged without moving either star.
- Correct feedback uses the approved bright synthesized marimba cue at an audible functional-feedback level. Playback now remains active for the full rendered cue so answer and result sounds cannot truncate one another.
- The result screen reports the number of words answered correctly as the earned-star total instead of converting the separate 1–3-star score rating.
- Correct-answer and quest-completion transitions no longer play bundled spoken praise.
- Read and Write now use a fixed two-miss limit. Parents can no longer configure this limit.
- Read listens for up to six seconds. Unclear audio and listening timeouts consume one try without becoming guardian accuracy evidence.
- After a correct Read response or the second Read miss, the app plays the correct pronunciation, pauses briefly, and advances.
- Write reveals the correct spelling only after the second miss.
- A retry that ends correctly still earns the child's per-word progress star. Immutable learning events separately preserve first-response correctness, prompt replay/help counts, and the final response for strict scheduling and mastery.
- Spell with Letters accepts A-Z, Delete/Backspace, and Return from an attached iPad physical keyboard while retaining the constrained on-screen keyboard and never invoking system text entry or prediction.

## Persistence and privacy

The progress bar derives earned slots from already persisted correct attempt
events when a quest resumes. No new child data, analytics, network request, or
persistent schema is introduced.
