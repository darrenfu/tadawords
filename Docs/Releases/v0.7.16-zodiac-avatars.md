# Tada Words v0.7.16 — Zodiac Profile Avatars

- Build: `2026072016`
- Issue: `#97`
- Batch: `zodiac-avatars-v0.7.16`

## User-visible change

The starter Profile picker now offers twelve original illustrated Chinese
zodiac animals in canonical order. The selected illustration appears wherever
the starter Profile avatar is shown, including first-run setup, Parents, the
child Profile chooser, and the collection's original-avatar card.

## Compatibility

Existing Profiles using the legacy `hare`, `fox`, `bear`, `owl`, `cat`, or
`dog` identifiers remain readable. Legacy choices are not presented for new
selection; they use their prior SF Symbol fallback until a parent chooses a new
zodiac avatar. Photo and earned treasure avatars are unchanged.
