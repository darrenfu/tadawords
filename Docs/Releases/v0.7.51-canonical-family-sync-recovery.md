# Tada Words 0.7.51 canonical Family Sync recovery

- Build: `2026072605`
- Risk tier: R4
- Issue / PR: `#145` / `#148`
- Distribution: Internal TestFlight only

This candidate adds an explicit, owner-authorized conflict-resolution flow.
The selected device publishes an immutable, fingerprint-verified generation;
a compare-and-swap pointer activates it without deleting CloudKit zones,
shares, or the previous generation. Updated devices must adopt that exact
generation before uploading. It preserves Profile UUIDs and local learning
data, requires a verified backup digest plus Local Authentication, rejects
shared or account-mismatched routes, and advances local fences only after
crash-replayable adoption.

The approved recovery target is Darren’s reading iPad (3). The expected
preflight manifest is two Profiles, 171 words, and 220 total sync records.
No other iPad, Profile identity, Apple Account, or app data may be changed.
