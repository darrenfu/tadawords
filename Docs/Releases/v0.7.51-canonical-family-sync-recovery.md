# Tada Words 0.7.51 canonical Family Sync recovery

- Build: `2026072603`
- Risk tier: R4
- Issue / PR: `#145` / `#148`
- Distribution: Internal TestFlight only

This candidate adds an explicit, owner-authorized recovery flow for replacing
divergent private Family Sync copies with the complete local snapshot from one
selected device. It preserves Profile UUIDs and local learning data, requires a
verified backup digest plus Local Authentication, rejects shared or
account-mismatched routes, and acknowledges local outbox records only after an
exact server read-back.

The approved recovery target is Darren’s reading iPad (3). The expected
preflight manifest is two Profiles, 171 words, and 220 total sync records.
No other iPad, Profile identity, Apple Account, or app data may be changed.
