# v0.7.43 — QA artifact cleanup

Build: `2026072417`  
Issue: #114  
Batch: `qa-artifacts-cleanup-v0.7.43`

This release removes obsolete tracked child directories below `QAArtifacts/`.
The root-level design and feature audit records remain in place. Historical
references now describe the prior observations rather than linking to deleted
screenshots.

The cleanup adds a source contract that fails if any child directory is added
below `QAArtifacts/`. It does not alter runtime behavior, persistence, CloudKit,
signing identity, or app data. Because the release updates app package metadata,
the normal exact-HEAD simulator and signed-device gates still apply.
